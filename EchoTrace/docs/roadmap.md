# Roadmap

## In the running v1

- Structured scope card (S, X, A, P)
- Two-party acceptance of an exact version hash
- One atomic request, statements, typed evidence, hash acknowledgement
- Early freeze and a browser-clock deadline, labeled as local
- Deterministic classification
- One local review round and a separate change-order agreement
- Local team list that cannot sign
- Docs, roadmap, privacy, security

## Not in v1

- Escrow, tokens, reputation
- Admin keys
- Web crawling as consensus input
- Email collection
- A backend signer
