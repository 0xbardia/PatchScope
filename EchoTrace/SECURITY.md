# Security disclosure

This project has not had an external audit.

Report a vulnerability with the affected file, a minimal reproduction, and the impact. Please do not include secrets, live credentials, or personal data in the report.

Give a reasonable window before any public write-up. Findings already known are listed in SECURITY_FINDINGS.md. A local-storage edit of the browser workspace is a known limit, not a chain compromise.

There is no bug bounty in this preview.
